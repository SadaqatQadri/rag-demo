# Northwind Gear Co. — Support Escalation Guide (Excerpt)

## Tier 1 (Front-line chat/email)
Handles order status, shipping questions, standard returns within policy, sizing questions, and loyalty program balance questions. Tier 1 has authority to issue refunds up to $50 without approval.

## Tier 2 (Escalation)
Handles warranty claims, disputes over "worn item" return classification, refunds over $50, and any request involving a damaged shipment. Tier 2 tickets must be opened within 24 hours of a Tier 1 handoff and include order number, photos (for damage claims), and a summary of what Tier 1 already tried.

## Tier 3 (Specialist / Management)
Handles chargebacks, legal complaints, accessibility complaints, and any request from a customer who has contacted support more than 3 times about the same order. Tier 3 response SLA is 2 business days.

## Auto-Escalation Triggers
A ticket is automatically flagged for Tier 2 review if it contains the words "lawyer," "chargeback," "BBB," or "lawsuit," or if the customer's order value exceeds $500.
